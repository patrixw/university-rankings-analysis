University Rankings Analysis
This project analyzes the global rankings of universities using a dataset with over 12,000 records. The analysis includes preprocessing, exploratory data analysis (EDA), and visualizations to uncover trends and insights.


Project Overview
The dataset contains the following columns:

University: Name of the university.
Country: Country where the university is located.
Region: Region within the country.
Global Rank: The global ranking of the university.
Features
Preprocessing:
Handles missing values and duplicate records.
Exploratory Data Analysis:
Distribution of universities by country and region.
Average rankings by country.
Visualizations of global ranking distribution.
Tools and Libraries
Python: For data processing and analysis.
Pandas: For data manipulation.
Matplotlib and Seaborn: For creating visualizations.
Visualizations
Top countries with the most universities.
Average global rankings by country.
Distribution of global rankings.
